Lookup table of algorithm parameters
====================================

General algorithm parameters
----------------------------

+---------------------------+--------------------------------------------------------------------------------------------------------------+
| algorParam.general.       | Description                                                                                                  |
+===========================+==============================================================================================================+
| isBET                     | Logical value of performing brain extraction in SEPIA                                                        |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fractional_threshold      | Corresponding to '-f' option in FSL's BET                                                                    |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| gradient_threshold        | Corresponding to '-g' option in FSL's BET                                                                    |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| isInvert                  | Use conjugate of the complex-valued data for processing                                                      |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| isRefineBrainMask         | Exclude high R2* voxels from the edge of the brain mask                                                      |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| brain_extraction_method   | New in v1.3.0. Method used for brain extraction when isBET is enabled: 'FSL bet (MEDI)', 'Otsu               |
|                           | thresholding', 'SynthStrip' or 'SynthStrip (no CSF)'                                                         |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| isDenoise                 | New in v1.3.0. Logical value of denoising the magnitude/phase data using Tensor-MPPCA before processing      |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| denoiseKernel             | New in v1.3.0. Denoising sliding-window kernel size, in mm                                                   |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| isUpsample                | New in v1.3.0. Logical value of upsampling the magnitude/phase data (via k-space zero-filling) before        |
|                           | processing                                                                                                   |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| target_resolution         | New in v1.3.0. Target isotropic voxel size to upsample to, in mm                                             |
+---------------------------+--------------------------------------------------------------------------------------------------------------+

Mask refinement algorithm parameters
-------------------------------------

    New in v1.3.0. Used by the I/O panel's 'Refine mask' option and the QSM panel's '2-pass masking' option (see below), both of which are backed by a common mask refinement pipeline (``MaskRefinementIOWrapper``/``MaskRefinementMacro``).

+---------------------------+--------------------------------------------------------------------------------------------------------------+

HEIDI (LSQR+HEIDI)

    New in v1.3.0. Several fields below (heidi_TikhonovRegularizationSusceptibility, heidi_solvingType, heidi_DipoleFilter, heidi_residualWeighting) are reserved for future functionality; their GUI controls are currently disabled and fixed at their default values.

+----------------------------------------------+-------------------------------------------------------------------------------------------+
| algorParam.qsm.                              | Description                                                                               |
+==============================================+===========================================================================================+
| heidi_tolerance                              | Convergence limit                                                                         |

+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_offsetUseBool                          | Automatic offset determination                                                            |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_isFourierDomainFormula                 | Construct the dipole kernel in the Fourier domain (true) or the spatial domain (false)    |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_TikhonovRegularizationSusceptibility   | Tikhonov regularisation setting (reserved; fixed at 'Default')                            |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_solvingType                            | Solver setting (reserved; fixed at 'Default')                                             |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_DipoleFilter                           | Dipole filter setting (reserved; fixed at 'Default')                                      |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_residualWeighting                      | Residual weighting; scaled internally by the field strength (reserved; fixed at its       |
|                                              | default)                                                                                  |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_PostProcCone_threshold                 | Threshold to define the ill-posed 'cone' in k-space (magnitude of dipole kernel below     |
|                                              | threshold)                                                                                |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_PostProcCone_tol                       | Convergence tolerance for cone post-processing                                            |
+----------------------------------------------+-------------------------------------------------------------------------------------------+
| heidi_PostProcCone_tolEnergy                 | Energy-based convergence tolerance for cone post-processing                               |

Chi-separation
^^^^^^^^^^^^^^

.. note::
    New in v1.3.0. Requires ONNX checkpoint files and the Deep Learning Toolbox Converter for ONNX Model Format support package; see :ref:`Chi-separation <method-qsm-chi-separation>` for setup instructions.

+---------------------------+--------------------------------------------------------------------------------------------------------------+
| algorParam.qsm.           | Description                                                                                                  |
+===========================+==============================================================================================================+
| solver                    | Chi-separation algorithm: 'Chi-separation-MEDI', 'Chi-separation-iLSQR', 'Chi-sepnet-R2*' or                 |
|                           | "Chi-sepnet-R2'"                                                                                             |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| Dr                        | Susceptibility anisotropy constant used by the selected solver (default 137; automatically set to 114 and    |
|                           | locked for the Chi-sepnet solvers)                                                                           |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| R2s                       | Path to an R2* map used by the selected solver                                                               |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| R2                        | Path to an R2 map (registered to R2*/GRE) used by the MEDI/iLSQR and 'Chi-sepnet-R2''' solvers               |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
